# honeybee_energy_ref/ — the package

Adds a `.ref` property slot to Honeybee-Energy objects for source/reference tracking. See `../context/ARCHITECTURE.md`.

## Modules

- `_extend_honeybee_energy_ref.py` — registers the `.ref` slot onto Honeybee objects (runs on import).
- `document_ref.py` — `DocumentReference` (document URI + thumbnail/full-size image URIs + generated identifier).
- `image_ref.py` — image reference objects.

## Subfolder

- `properties/` — `hb_obj.py`, the per-host-object property class owning `to_dict()`/`from_dict()` for the `.ref` data.

## Notes
- IPy2.7-safe (`# -*- Python Version: 2.7 -*-`); serialization must stay backward-compatible. Tests: `../tests/`.
