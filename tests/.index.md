# tests/ — pytest suite

pytest suite for honeybee-ref. Run with `python -m pytest`. Warnings are errors.

## Contents

- `test_document_ref.py`, `test_image_ref.py`, `test_external_identifier.py` — the reference objects.
- `test_constructions.py`, `test_materials.py` — `.ref` data on Honeybee-Energy constructions/materials (serialization round-trip).
